# اعلان‌بان — اینفوگرافیک یک‌صفحه‌ای CRM پیام‌محور چندکاناله

صفحه‌ی معرفی محصول **اعلان‌بان** (CRM پیام‌محور خودمیزبان با تمرکز ویژه بر مدیریت و اتوماسیون اینستاگرام)،
ساخته‌شده به‌صورت کامل با HTML / CSS / JS خالص — بدون فریم‌ورک، بدون وابستگی بیرونی و بدون CDN.

زبان طراحی: **Modern 3D Claymorphism / Clean UI / فارسی و راست‌چین**، بر پایه‌ی پالت رنگی سند مرجع
(سبز جنگلی عمیق `#0B3C39`، فیروزه‌ای `#009E91`، نعنایی `#17D5C6`، کهربایی `#FFC107`، بنفش AI `#7C3AED` و …).

---

## فونت

فونت صفحه **ری (Ray)** است؛ همان فونت‌فایلی که در همین مخزن گیت‌هاب قرار دارد
(`ray (1).zip`). فایل‌های TTF با `fontTools` به `woff2` تبدیل شده‌اند تا در وب سبک و سریع بارگذاری شوند:

```
assets/fonts/ray/Ray-Light.woff2       weight 300
assets/fonts/ray/Ray.woff2             weight 400
assets/fonts/ray/Ray-Medium.woff2      weight 500
assets/fonts/ray/Ray-Bold.woff2        weight 700
assets/fonts/ray/Ray-ExtraBold.woff2   weight 800
assets/fonts/ray/Ray-Black.woff2       weight 900
assets/fonts/ray/Ray-ExtraBlack.woff2  weight 950
```

فونت جایگزین در صورت نبود «ری»: **وزیرمتن** (`assets/fonts/vazirmatn/`) و سپس
IRANSans، شبنم، یکان‌بخ، Tahoma و Arial.

> در سند راهنما، این فونت‌ها به‌عنوان فونت‌های **ویجت** نام برده شده‌اند؛ در این صفحه فونت اصلی خودِ اینفوگرافیک «ری» است.

## ساختار پروژه

```
index.html                     صفحه‌ی کامل (یک صفحه، ۲۳ بخش)
assets/css/fonts.css           تعریف @font-face برای ری و وزیرمتن
assets/css/style.css           توکن‌های رنگ، کارت‌های کِلِی، ماکاپ‌های پنل، ریسپانسیو، چاپ
assets/js/app.js               پیشرفت مطالعه، نمایان‌شدن تدریجی، تب‌ها، فهرست موبایل، بخش فعال
assets/img/hero.png            رندر سه‌بعدی سربرگ (بدون متن و بدون لوگوی ناخواسته)
assets/fonts/…                 فونت‌های وب
screenshots/                   اسکرین‌شات‌های گرفته‌شده از صفحه (دسکتاپ ۱۴۴۰px و موبایل ۴۱۴px)
```

## اجرا

هیچ ابزار ساختی لازم نیست؛ فقط فایل را باز کنید یا یک سرور ساده اجرا کنید:

```bash
python3 -m http.server 8080
# سپس http://127.0.0.1:8080/
```

## دقت محتوایی

در نوشتن متن‌ها به محدودیت‌های مستندشده‌ی محصول پایبند شده است؛ برای نمونه:

- اتصال چندپیجی اینستاگرام از طریق **YarAPI** و به‌عنوان *روش اتصال* نمایش داده شده، نه نام محصول.
- **صفیر بله** فقط ارسال است و مسیر رسمی دریافت پاسخ ندارد.
- **ایمیل ورودی** پشتیبانی نمی‌شود (فقط ارسال SMTP).
- انتشار از API برای **عکس JPG** است؛ ویدیو، چندعکسی و زمان‌بندی انتشار از API پشتیبانی نمی‌شود.
- تخصیص چرخشی اپراتور، مدیریت شیفت و SLA به‌عنوان قابلیت پیاده‌شده معرفی **نشده‌اند**.
- هیچ نام سازنده، نسخه‌ی نرم‌افزار یا مالکیت حقوقی‌ای که در سند مرجع نبوده، اضافه نشده است.
